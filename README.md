# ToTheHome

> 죽은 강아지가 주인의 냄새를 쫓아 집으로 돌아가는 꿈 이야기.
> 웹/모바일 겸용 2D 사이드스크롤 플랫포머. **대사도 문자도 없다.**

---

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 로 정적 빌드
npm run preview  # 빌드 결과 확인
```

**AI 에셋이 하나도 없어도 바로 플레이된다.** 실제 그림/소리가 없는 자리는 코드로 그린
플레이스홀더가 대신 채운다. 소리는 SFX 만 WebAudio 로 합성해 내고 BGM 은 조용하다.

주소 뒤에 `?placeholder=1` 을 붙이면 실제 에셋을 전부 무시하고 임시 그림으로만 돌린다.
에셋 없이도 게임이 도는지 확인할 때 쓴다.

```
http://localhost:5173/?placeholder=1
```

## 에셋 넣기

```
assets-src/   ← 원본을 여기에 넣는다 (git 에 올리지 않음)
     ↓  npm run assets:prepare
public/assets/  ← 게임이 읽는 것 (배경 제거 · 격자 정렬 · 축소 · ogg 변환)
```

```bash
npm run assets:prepare   # 이미지 + 오디오 전처리
npm run assets:prepare -- --only images
npm run dev
```

전처리에는 Python(Pillow, numpy)과 ffmpeg 가 필요하다.

```bash
pip install pillow numpy
```

AI 생성 에셋은 크기가 제각각이고 "투명 배경"을 체커보드나 검은 그라데이션으로 그려 주는
일이 잦다. 전처리가 그걸 정리한다 — 자세한 내용과 재생성용 프롬프트는
[.docs/assets-images2.md](.docs/assets-images2.md), 움직이는 것들을 8프레임으로 굽는
프롬프트는 [.docs/assets-actors.md](.docs/assets-actors.md), 1차 결과 리뷰는
[.docs/asset-review.md](.docs/asset-review.md) 참고.

## 조작

| 입력 | 동작 |
|---|---|
| `←` `→` / `A` `D` | 이동 |
| `Space` / `↑` / `W` | 점프 (누른 시간만큼 높이 조절) |
| `Shift` | 도움닫기 (한 방향을 0.45초 유지해도 자동 진입) |
| `↓` / `S` | 아래쪽 보기 — 카메라가 스르륵 내려가 발밑을 비춘다 |
| `↓` + 점프 | 딛고 선 발판을 통과해 내려가기 (맨 아래 지면에서는 안 된다) |
| `E` / `Enter` | 상호작용 (세이브 포인트 · 도착 지점) · 쥐고 있으면 냄새 맡기 |
| `Esc` | 일시정지 |

소리 크기는 **일시정지 패널**과 **타이틀 오른윗 단추**에서 맞춘다. 글자를 쓰지 않으므로
왼쪽이 낮고 오른쪽이 높은 계단 막대다. 고른 크기는 저장된다.

모바일에서는 좌하단 방향 버튼과 우하단 점프·상호작용 버튼이 나타난다.

## 구성

```
게임 시작 ─┬─ 발자국: 처음부터
           └─ 집    : 이어하기 (저장이 있을 때만 · 집으로 흘러드는 냄새가 붙는다)
                 ↓
프롤로그(4컷) → 스테이지 1 도시 → 2 해안가 → 3 산 → 4 들판 → 엔딩
```

| 스테이지 | 컨셉 | 세이브 포인트 모션 |
|---|---|---|
| 1 도시 | 아직 깨지 않은 도시에서 길을 찾는 첫 여정. 기초 조작을 배운다 | 모래 놀이터에서 **땅파기** |
| 2 해안가 | 주인이 차로 오가던 길. 파도와 좁은 도로 | 포장마차 그늘에서 **낮잠** |
| 3 산 | 집은 산 너머. 가장 어렵다 | 계곡 연못에서 **물장구** |
| 4 들판 | 함께 살던 곳. 위험이 없다 | 공을 **코로 툭툭** |

이미 저장한 지점에서 다시 상호작용해도 모션은 그대로 재생된다 — 강아지는 그냥 거기서 노는 것.

## 기억 조각

스테이지마다 **2개**가 숨어 있다. 전부 **정규 루트에서 벗어난 자리**에 있어서, 냄새를 따라
가기만 하면 하나도 못 줍는다. 옥상으로 올라가거나, 지면 틈으로 내려가거나, 왼쪽으로
되돌아가야 닿는다.

- 화면 왼쪽 위에 그 스테이지의 개수만큼 그림이 뜨고, 주운 것만 켜진다 (숫자는 쓰지 않는다)
- 놓쳐도 진행에 지장이 없다. 냄새는 도착까지의 최단 경로만 가리키므로 기억 조각 쪽으로는 안 간다
- **엔딩에서 방 벽의 빈 액자 위로 모아 온 만큼 빛이 켜진다**

## 맵 관리 툴

```bash
npm run dev        # http://localhost:5173/editor.html
```

**점만 찍으면 된다.** 출발 · 발판 · 세이브 · 수집 · 도착. 순서도 방향도 없다.
"생성"을 누르면 그 점들에 발판을 놓고, **모든 발판을 서로 오갈 수 있도록** 사이를 이어 준다.

제자리에서 올라가야 하는 자리는 **길게 계단식으로** 돌려 놓는다. 한 방향으로 쭉 가며
오르고, 끝에서 꺾어 되돌아오면서 더 올라 x 를 맞춘다 — 산길의 갈지자 등산로와 같다.
좌우좌우로 흔들어 올리면 오르기도 답답하고 사다리를 세워 둔 것처럼 보인다.

잇는 길은 전부 **올라갈 수 있는 연결**로만 만든다 — 한 칸 높이차 84px, 가로 190px 안.
이런 연결은 위로도 아래로도 지날 수 있어서(올라갈 땐 뛰고 내려올 땐 떨어지면 된다),
이것만으로 이어 두면 **떨어졌다가 돌아 올라가지 못하는 자리가 생기지 않는다.**
바닥은 끊지 않고 쭉 깐다. 구멍을 파는 순간 "떨어지면 죽는 자리"가 되기 때문이다.

높이가 달라지는 칸은 **반드시 옆으로 비켜선다** — 윗칸과 아랫칸이 x 를 나눠 가지는 길이는
1px 까지다. 겹치면 계단이 아니라 사다리가 된다. 아랫칸에 서면 머리 위가 막혀 있고, 위로
가려면 옆으로 비켜서야 하는데 비켜설 칸이 곧 덮고 있는 칸이기 때문이다. 이미 깔린 선반 밑을
길이 지나갈 때도 비켜설 자리를 먼저 찾는다.

사방이 막히는 두꺼운 땅은 그 **밑에 설 자리와 뛸 자리**(몸 40 + 점프 96 = 140px)를 비워 둔다.
자리가 없으면 위에서만 밟히는 연석·판자로 낮춰 놓는다 — 그런 것은 아래에서 뛰어 뚫고
올라갈 수 있고 ↓ + 점프로 통과해 내려갈 수 있어서 길을 막지 않는다.

점을 잇기만 하면 가운데를 허브 삼는 별 모양이 되고 매번 같은 그림이 나온다. 그래서
찍지 않은 자리와 **가장자리 너머**에도 선반을 뭉치게 흩어 놓고(살), 빙 돌아야 닿는 곳에
지름길을 놓고(고리), 짧은 막다른 가지를 뻗는다(곁길). 여기에 씨앗 난수를 물려서
**같은 점이라도 "다시"를 누를 때마다 다른 지형**이 나온다.

- 좌클릭 = 점 찍기 · Shift+드래그 = 화면 이동 · 휠 = 확대
- **생성** — 지형을 만들어 미리 보여 주고, 전부 오갈 수 있는지 검사 결과를 알려 준다.
  넓은 자리에는 소품을 세우고 지나가는 길 위로 나는 것을 띄운다.
  **테마에 맞는 위험 요소도 같이 놓는다** — 딛고 설 만큼 넓은 자리에만, 서로 520px 씩
  벌려서. 도시 0.9 · 해안 1.1 · 산 1.5 개(1000px 당)이고 들판에는 두지 않는다.
  자동차는 길을 900px 로 잘라 양옆에 안전지대를 남기고, 한 길의 차들은 박자를 맞춰
  **7.4초는 반드시 비게** 한다 — 달려서 건너는 데 3초이므로 갑절에 예고 시간을 더한
  값이다. 출발 지점에서 3600px 안에는 차선을 놓지 않는다
  **출발에서 도착까지의 최단 경로 3분의 1마다 중간 세이브를 저절로 놓는다** — 찍어 둔
  세이브 가까이(700px 안)면 겹치므로 놓지 않고, 발밑이 두꺼운 자리를 골라 앉힌다
- **다시** — 같은 점으로 다른 지형. **살** 슬라이더로 지형을 얼마나 붙일지 조절한다
- **확정** — `src/data/layouts/stage<N>.json` 으로 저장한다. 게임을 새로고침하면 반영된다
- **되돌리기** — 저장본을 지운다. 손으로 짠 배치로 돌아간다

## 언어를 쓰지 않는다

강아지의 시점이므로 화면 어디에도 문자가 없다.

- 메뉴·UI는 전부 픽토그램 (발자국 / 뼈다귀 / 집 / 코). 타이틀 가운데 줄에는 **시작하는
  방법만** 놓고, 소리 크기와 스프라이트 넣기는 오른윗 도구 자리로 뺀다
- **모든 위험은 나타나기 2초 전부터 미칠 범위 전체를 옅은 붉은색으로 깜빡인다** —
  차선 전부, 낙석이 떨어져 내릴 기둥 전부, 멧돼지가 돌진할 거리 전부
- 튜토리얼은 월드에 박힌 안내판 그림. 지나가면 뒤에 남고, 돌아오면 다시 볼 수 있다
- 길 안내는 **냄새 입자**가 대신한다. 평소에는 보이지 않고, 냄새를 맡는 동안에만 반짝인다.
  미리 그려 둔 한 줄기가 아니라 **맡을 때마다 지금 자리에서** 도착까지의 최단 경로를 찾는다
- 도착 지점은 집 그림과 빛기둥이다. 도착은 **상호작용해야** 통과다 (출발 지점에는 아무것도 두지 않는다 — 강아지가 이미 거기 서 있다)
- 체력·점수·타이머 같은 숫자 표시가 없다

## 구조

```
src/
├─ main.js              Phaser 부트스트랩
├─ config.js            조작 수치 · 팔레트 · 테마
├─ scenes/              Boot · Preload · Title · SpriteImport
│                       Prologue · Stage · Ending · Hud
├─ objects/             Dog · SavePoint · Hazards · Platforms · Decor
├─ systems/             AssetLoader · PlaceholderArt · PlaceholderScenery
│                       Input · Save · Audio · Layout
└─ data/                stage1~4 레벨 데이터
```

- 레벨은 전부 `src/data/stage*.js` 의 **데이터**다. 지형·위험·소품을 이 파일들에서 조정한다.
- `PlaceholderArt` / `PlaceholderScenery` 는 캔버스로 임시 그림을 그린다. 실제 에셋이
  들어오면 호출되지 않으므로, 에셋을 다 채운 뒤 지워도 된다.
- 진행은 `localStorage` 의 `tothehome.save.v1` 하나에 저장된다.

## 직접 만든 스프라이트로 플레이하기

타이틀 **오른윗 뼈다귀** 아이콘을 누르면 로컬 PNG를 그 자리에서 넣어볼 수 있다.
파일명이 에셋 이름과 같아야 하고(`dog_walk.png` → `dog_walk`), 가로 8프레임 시트여야 한다.
이 주입은 저장되지 않는다. 영구 적용은 `public/assets/sprites/` 에 넣으면 된다.
