# 관리 툴이 확정한 배치

`editor.html` 에서 "확정"을 누르면 여기에 `stage<번호>.json` 이 생긴다.
파일이 있으면 `stages.js` 가 **손으로 짠 지형 대신 그것을 쓴다.**

- 지형(지면·턱)·냄새·기억 조각·출발·도착·세이브 포인트·**소품**이 덮인다
- 지형이 통째로 바뀌므로 지형에 매달려 있던 것(위험 요소·움직이는 발판·안내판)은 버린다
- 소품과 하늘을 나는 것은 생성기가 지형을 보고 놓는다. 예전에 확정해 둔 배치처럼
  소품이 없으면, 손으로 놓은 것을 x 는 두고 새 지면 높이로 다시 앉힌다

생성기를 고친 뒤에는 관리 툴을 다시 열 필요 없이 저장된 씨앗으로 다시 구우면 된다.

```bash
node scripts/rebuild-layouts.mjs [--dry-run]
```

되돌리려면 관리 툴에서 "되돌리기"를 누르거나 이 폴더의 json 을 지우면 된다.
