## 5차

1. 자동차 방해물 회피가 너무 어렵다. 특히 1스테이지는 거의 생성 지점까지 가야 올라가서
   회피가 가능하다 — 시작부터 이러면 곤란하다
2. 방해물 생성 2초 전에 옅은 붉은색으로 깜빡이고 나타나면 좋겠다. **방해물 전체 범위**를
   모두 표시해야 한다
3. 2스테이지에서 다음 맵으로 넘어가려니 상호작용이 안 된다
4. 타이틀 2·3번째 버튼 용도를 모르겠다. 2번째 버튼 안의 버튼들과 상단 UI 도 뭔지 모르겠다
5. 2스테이지 세이브 포인트 오브젝트가 너무 작다. 세이브 포인트 오브젝트는 소형 발판
   2개를 붙인 너비로, 반드시 소형 발판 2개 이상 너비의 판 위에만 있어야 한다

1. 산에서 다리 타일은 쓰지 말자. 그냥 분위기를 완전 헤친다
2. 산에서 부엉이는 가만히 서있는 모션인데 날아다니고 있어서 이상함. 차라리 땅에
   세워두는 게 나을듯
3. 산에서 추락하는 돌 + 멧돼지 조합이 있는데 이거 회피가 불가능함. 아니면 멧돼지는
   점프로 피할 수 있게 크기 작게 하던가
