# ToTheHome — 게임 디자인 문서

> 죽은 강아지가 주인의 냄새를 쫓아 집으로 돌아가는 꿈 이야기.
> **대사·문자 없음.** 모든 전달은 그림·모션·소리·픽토그램으로만 한다.

---

## 1. 개요

| 항목 | 값 |
|---|---|
| 장르 | 2D 사이드스크롤 플랫포머 / 내러티브 |
| 플랫폼 | 웹 (데스크톱 + 모바일 브라우저 겸용) |
| 기술 스택 | Phaser 3 + Vite (JavaScript) |
| 기준 해상도 | 960 × 540 (16:9, 가로로 긴 화면) |
| 스케일 모드 | `Scale.FIT` + `CENTER_BOTH`, 세로 기기에서는 가로 회전 유도 오버레이 |
| 아트 | 픽셀아트풍 / 수채 파스텔. 8프레임 스프라이트 애니메이션 |
| 1회차 플레이타임 | 약 20~30분 |

### 톤
따뜻한 슬픔. 무섭거나 잔혹하지 않다. 죽음은 "빛으로 흩어졌다가 다시 모이는" 이미지로만 표현한다.

### 서사는 은유로만 드러낸다

**강아지가 죽었다는 것을 화면에 대고 설명하지 않는다.** 장소로도, 소품으로도 말하지 않는다.
납골당·무덤·영정처럼 사실을 지목하는 장치는 두지 않는다. 대신 이런 것들만 남긴다.

- 빛으로 흩어졌다가 다시 모이는 부활 연출
- 아무도 없는 이른 아침의 도시, 어디서 왔는지 말하지 않는 시작
- 프롤로그의 아이와 엔딩의 어른 사이에 놓인 시간의 간격
- 엔딩에서 껴안는 순간이 빛에 가려지고, 깨어 보니 아무도 없다는 것
- 문 앞 바닥에 남은 냄새 입자 하나

플레이어가 알아채면 그때 슬퍼지고, 알아채지 못하면 그냥 집에 가는 이야기다.
**둘 다 맞는 이야기여야 한다.**

## 2. 언어 배제 원칙 (No-Language Rule)

강아지의 시점이므로 게임 내 어떤 문자도 노출하지 않는다.

- **UI 라벨 금지** → 픽토그램만 사용 (▶ 발자국 = 시작, 🦴 뼈다귀 = 스프라이트 추가 등)
- **튜토리얼** → 월드에 박힌 안내판 이미지. 키캡 그림 + 화살표 + 강아지 실루엣으로만 설명
- **스토리** → 프롤로그/엔딩의 무성 연출 컷과 배경 시간대 변화로만 전달
- **숫자 금지** → 체력·점수·타이머 없음
- 예외: 브라우저 탭 타이틀, 접근성용 `aria-label` (화면에 보이지 않음)

## 3. 조작

### 3.1 키보드

| 입력 | 동작 |
|---|---|
| `←` `→` / `A` `D` | 이동 |
| `Space` / `↑` / `W` | 점프 (누르는 시간에 따라 높이 가변) |
| `Shift` (홀드) | 도움닫기 — 즉시 가속 |
| `↓` / `S` | 웅크리기 · 냄새 맡기 (냄새 길 힌트 강조) |
| `E` / `Enter` | 상호작용 (세이브 포인트, 안내판) |
| `Esc` | 일시정지 (픽토그램 메뉴) |

### 3.2 터치 (모바일)

- 좌하단: 가상 D-pad (좌 / 우 / 아래)
- 우하단: 점프 버튼 (홀드로 높이 조절), 상호작용 버튼(상호작용 가능 대상이 있을 때만 나타남)
- 도움닫기: **한 방향으로 0.45초 이상 계속 이동하면 자동으로 러닝 상태 진입**
  (키보드도 동일 규칙 적용 + `Shift`로 즉시 진입 — 두 입력의 체감을 통일)

### 3.3 조작 감각 파라미터 (초기값)

```
걷기 속도        160 px/s
달리기 속도      300 px/s
가속 진입 시간   0.45 s (홀드 유지 시)
중력             1400 px/s²
점프 초기 속도   -520 px/s
가변 점프 컷     버튼을 떼면 상승 속도 × 0.45
코요테 타임      0.12 s   (발판을 벗어난 뒤에도 점프 허용)
점프 버퍼        0.15 s   (착지 직전 입력을 기억)
러닝 점프 보정   수평 속도 240 이상이면 점프 초기 속도 -560
```

> 코요테 타임과 점프 버퍼는 "조작이 억울하지 않은" 플랫포머의 최소 조건이므로 반드시 넣는다.

## 4. 코어 메커닉

1. **점프** — 가변 높이. 스테이지 1에서 학습.
2. **타이밍 통과** — 주기적으로 움직이는 위험(차량, 낙하물, 파도, 야생동물)을 기다렸다 지나간다.
3. **도움닫기** — 일정 시간 달리면 속도가 붙어 긴 간격을 넘을 수 있다.
4. **냄새 추적 (Scent Trail)** — 진행 방향과 다음 발판 위에 옅은 냄새 입자가 떠 있다.
   `↓`(냄새 맡기)를 하면 3초간 입자가 밝아진다. **언어 없이 길을 안내하는 핵심 장치.**
5. **세이브 포인트** — 스테이지 중간 1곳. 상호작용 시 스테이지 고유의 "노는 모션"이 재생된다.

## 5. 세이브 / 부활

### 5.1 흐름

```
세이브 포인트 접근
  → 머리 위에 상호작용 픽토그램 표시
  → 상호작용 입력
  → 스테이지 전용 모션 재생 (조작 잠금, 1.5~2.5초)
  → 빛 파동 이펙트 + 저장 징글
  → 체크포인트 갱신
```

**이미 저장한 포인트에서 다시 상호작용하면** 저장은 다시 일어나지 않지만
**같은 모션을 다시 재생한다.** (요청서 명시 — 강아지는 그냥 거기서 노는 것)

### 5.2 스테이지별 세이브 모션

| 스테이지 | 세이브 포인트 | 모션 |
|---|---|---|
| 1 도시 | 모래 놀이터 | 앞발로 모래를 파헤친다 (`dog_dig`) |
| 2 해안가 | 파라솔 꽂힌 포장마차 노점 | 그늘에 엎드려 한숨 잔다 (`dog_sleep`) |
| 3 산 | 계곡 연못 | 얕은 물에서 물장구친다 (`dog_splash`) |
| 4 들판 | 놀이용 공 | 코로 공을 툭툭 건드린다 (`dog_ball_nudge`) |

### 5.3 사망 / 부활

- 위험 접촉 또는 낙하 → **빛 입자로 흩어짐** (0.8초) → 마지막 체크포인트에서 **입자가 다시 모여 형체가 됨** (0.8초)
- 페널티·목숨·카운터 없음. 화면이 잠깐 하얗게 물드는 정도의 연출.
- 스테이지 4에는 사망 요소가 없다.

### 5.4 저장 데이터 (localStorage)

```json
{
  "version": 1,
  "stage": 2,
  "checkpoint": "s2_save",
  "prologueSeen": true,
  "clearedStages": [1],
  "customSprites": false
}
```
키: `tothehome.save.v1`

## 6. 씬 흐름

```
Boot → Preload → Title
                   ├─ [발자국 아이콘] 그냥 시작 ─┐
                   └─ [뼈다귀 아이콘] 스프라이트 추가 → SpriteImport ─┘
                                                          ↓
Prologue (4컷) → Stage1 → Stage2 → Stage3 → Stage4 → Ending → Title
```

- 이어하기 저장 데이터가 있으면 타이틀에 **세번째 픽토그램(집 아이콘)** 이 추가로 나타난다.
- 스테이지 전환은 화면 페이드 + 냄새 입자가 다음 방향으로 흘러가는 연출.

## 7. 프롤로그 (무성 4컷)

각 컷은 자동 스크롤되는 연출 씬이며, 입력은 "건너뛰기"만 받는다.

| 컷 | 배경 | 연출 |
|---|---|---|
| 1 | **아침** 들판 | 강아지와 주인(아이)이 뛰논다. **강아지가 약간 앞선다.** |
| 2 | **낮** 들판 | 둘이 **나란히** 달린다. |
| 3 | **저녁** 들판 | **주인이 앞선다.** 강아지의 걸음이 느려진다. |
| 4 | **밤** 집 안 | 자고 있는 강아지에게 주인이 걸어온다 → **암전** |

> 컷 1~3의 배경은 스테이지 4와 **동일한 들판 에셋**을 시간대만 바꿔 사용한다.
> 컷 4의 집 안은 **엔딩과 동일한 실내 에셋**을 사용한다. (수미상관)

## 8. 스테이지 설계

공통 규칙
- 진행 방향은 **항상 오른쪽**.
- 각 스테이지는 3구간(도입 / 전개 / 절정)으로 나누고, 세이브 포인트는 2구간 시작 지점에 둔다.
- 스테이지 끝에는 다음 장소를 암시하는 배경 요소가 보인다.

### 길은 하나가 아니다

**앞으로 가면서 틈만 피하는 지도는 만들지 않는다.** 구간마다 아래 중 하나 이상을 섞는다.

| 장치 | 하는 일 | 예 |
|---|---|---|
| **수직 갈림길** | 올라가면 다른 길이 열리고, 내려와 원래 길에 합류한다 | 1-도시 옥상 (담장 → 옥상 → 움직이는 발판) |
| **막다른 갈림길** | 갔다가 **되돌아 나와야** 한다. 유일하게 왼쪽으로 가는 구간 | 2-해안 방파제 끝 |
| **평행 루트** | 같은 구간을 다른 높이로 지난다. 안전하지만 느리다 | 2-해안 도로 위 높은 길 (차가 닿지 않는다) |
| **아래로 내려가기** | 지면 틈으로 떨어졌다가 다시 올라온다 | 1-도시 갓길 아래, 3-산 물가 바위 |

- 갈림길 끝에는 **기억 조각**을 둔다. 그것이 갈림길에 들어갈 이유다.
- 갈림길은 놓쳐도 진행이 막히지 않는다. 냄새 입자는 언제나 **정규 루트만** 가리킨다.

## 8.4 맵 관리 툴

지형을 손으로 짜면 발판마다 점프가 닿는지 계산해야 하고, 그렇다고 전부 자동으로 만들면
"여기쯤에 세이브가 있으면 좋겠다" 같은 의도를 넣을 수가 없다.
**어디에 무엇이 있을지는 사람이, 그 사이를 잇는 일은 기계가** 하도록 나눈 것이 이 툴이다.

```
npm run dev  →  http://localhost:5173/editor.html
```

### 사람은 점만 찍는다

| 점 | 놓이는 것 |
|---|---|
| 출발 | 시작 자리 (하나) |
| 발판 | 밟을 수 있는 자리 |
| 세이브 | 중간 저장 지점 (여러 개) |
| 수집 | 기억 조각. 발판이 52px 아래에 깔린다 |
| 도착 | 스테이지 끝 (하나) |

**순서도 방향도 없다.** 흩어 놓기만 하면 된다.

### 기계는 전부 오갈 수 있게 잇는다

지켜야 할 것은 하나다 — **모든 발판에서 모든 발판으로 갈 수 있어야 한다.**
떨어지는 건 공짜라서 아래로 가는 길은 저절로 생기지만, 그게 함정이 된다.
떨어졌는데 돌아 올라갈 수 없으면 게임이 거기서 막힌다.

그래서 잇는 길은 전부 **올라갈 수 있는 연결**로만 만든다.

```
한 칸의 높이차  <= 84px   (점프 최고 상승 96px 에서 여유를 뺀 값)
한 칸의 가로 간격 <= 190px  (달리며 뛰어 240px 에서 여유를 뺀 값)
```

이 조건을 지키는 연결은 **위로도 아래로도** 지날 수 있다. 올라갈 땐 뛰고 내려올 땐
떨어지면 되기 때문이다. 그러므로 이런 연결로만 전부 이어 두면 **오갈 수 있음이 저절로
보장된다.** 방향을 따로 따질 필요가 없다.

### 점을 잇기만 해서는 지도가 안 된다

최단 거리로 잇기만 하면 가운데 한 점을 허브 삼는 **별 모양**이 되고, 몇 번을 돌려도 같은
그림이 나온다. 지도처럼 보이려면 세 가지가 더 있어야 한다.

| | 왜 필요한가 |
|---|---|
| **살** | 찍지 않은 자리와 **가장자리 너머**에도 선반이 있어야 "그 너머에도 길이 있다"로 읽힌다 |
| **고리** | 갈 수 있는 길이 하나뿐이면 복도다. 다른 길로 돌아올 수 있어야 지도다 |
| **곁길** | 아무 데도 닿지 않고 끝나는 짧은 가지. 가 볼 만한 구석을 만든다 |

살은 **몇 군데로 뭉치게** 놓는다. 고르게 흩뿌리면 발판이 화면을 균일하게 덮어 벽지처럼
보인다. 뭉친 데와 빈 데가 있어야 "저기는 오르는 곳, 여기는 지나가는 곳" 하고 구역이 읽힌다.

이 셋과 잇는 순서에 **씨앗 난수**를 물린다. 같은 점 배치라도 씨앗이 다르면 다른 지형이
나오고("다시" 버튼), 같은 씨앗이면 언제나 같은 지형이다. "살" 슬라이더로 얼마나 붙일지
조절한다 (0 이면 점만 잇는다).

### 만드는 순서

1. **바닥을 쭉 깐다.** 구멍을 파면 그 자리가 곧 "떨어지면 죽는 자리"가 된다.
   어디서 떨어져도 바닥에 닿고, 바닥은 다른 발판과 이어져 있으므로 다시 올라갈 수 있다.
2. 찍은 점마다 발판을 놓는다. 바닥 높이에 있는 점은 이미 바닥이 있으므로 그냥 둔다.
3. **살을 붙인다** — 뭉친 자리마다 선반(발판 2~4개를 한 줄로)을 흩어 놓는다.
   발판을 하나씩 놓으면 징검다리로 보이고, 줄로 놓아야 지형으로 읽힌다.
4. 서로 오갈 수 있는 것끼리 묶어 **덩어리**를 만든다.
5. 덩어리가 둘 이상이면, 서로 다른 덩어리에 속한 짝 중 **가까운 후보 몇 개에서 무작위로**
   골라 사다리를 놓는다. 늘 가장 가까운 것만 고르면 매번 같은 그림이 된다.
6. 덩어리가 하나가 될 때까지 5를 되풀이한다.
7. **고리**를 놓는다 — 가깝게 붙어 있는데 빙 돌아야 닿는 두 곳에 지름길을 만든다.
8. **곁길**을 몇 개 뻗는다. 사다리로 잇기 때문에 들어간 만큼 되돌아 나올 수 있다.
9. 냄새 입자는 출발에서 도착까지 **최단 경로 한 줄기**에만 뿌린다.
   갈림길이 많아도 길잡이는 하나여야 한다.

- "확정"하면 `src/data/layouts/stage<N>.json` 에 저장되고 게임이 그것을 쓴다.
- "되돌리기"를 누르면 저장본을 지운다. 손으로 짠 배치로 돌아간다.
- 지형에 매달려 있던 위험 요소·안내판은 버려지고, 소품은 새 지면 높이로 다시 앉는다.

## 8.5 기억 조각 (수집 요소)

스테이지마다 **2개**, 모두 **정규 루트에서 벗어난 자리**에 있다. 냄새를 따라가기만 하면
전부 지나친다. 위로 올라가거나 아래로 내려가 보아야 닿는다.

| 스테이지 | 어디에 | 가는 법 |
|---|---|---|
| 1 도시 | 옥상 / 갓길 아래 | 담장 위로 한 단 더 / 지면 틈으로 내려갔다 올라온다 |
| 2 해안 | 방파제 끝 / 도로 위 높은 길 | 왼쪽 위로 되돌아간다 / 가드레일을 타고 오른다 |
| 3 산 | 물가 바위 / 능선 나뭇가지 | 냇가 직전 틈으로 내려간다 / 낙석을 뚫고 올라간다 |
| 4 들판 | 큰 나무 위 / 언덕 꼭대기 | 둘 다 그냥 올라가면 된다. 위험이 없다 |

### 규칙

- **문자도 숫자도 쓰지 않는다.** 화면 왼쪽 위에 그 스테이지의 개수만큼 그림을 늘어놓고,
  주운 것만 켠다. 몇 개가 남았는지는 꺼져 있는 그림의 수가 말한다.
- 주우면 빛이 위로 흩어진다. 저장은 즉시 되고, 죽어도 다시 줍지 않는다.
- **보상은 엔딩에 있다.** 방 벽에 걸린 빈 액자 위로, 모아 온 개수만큼 빛이 하나씩 켜진다.
  하나도 못 모았으면 아무 일도 일어나지 않는다. 그래도 이야기는 끝난다.

---

### 난이도 예산

성향이 다르면 **밀도로 구분한다.** 길이만 늘리면 지루해지고, 위험만 늘리면 벌 받는 느낌이 든다.

| 스테이지 | 길이 | 위험 / 1000px | 지면 틈 | 성격 |
|---|---|---|---|---|
| 1 도시 | 5,700 | **0.9** | 5 | 하나씩 배운다. 위험끼리 멀찍이 떨어뜨린다 |
| 2 해안 | 6,300 | **1.1** | 4 | 양쪽에서 오는 것을 동시에 본다 |
| 3 산 | 7,100 | **1.8** | 9 | 멈춰 설 곳이 없다. 무너지는 발판 8개 |
| 4 들판 | 4,200 | **0** | **0** | 걷기만 한다. 냄새가 뒤로 갈수록 짙어진다 |

- 스테이지 4는 **지면에 틈이 하나도 없다.** 사망 요소가 없다는 규칙은 낙사도 포함한다.
- 넓은 틈(도달거리 240px 초과)은 반드시 중간 발판으로 건널 수 있어야 한다.
- 무너지는 발판은 **바로 아래에 지면이 있는 곳**부터 가르친다 (스테이지 3 도입, x=1660).

### 8.1 스테이지 1 — 도시 (튜토리얼)

- **컨셉**: 아직 깨어나지 않은 도시에서 눈을 뜨고, 주인의 냄새를 쫓기 시작하는 첫 여정.
  **어디에서 왔는지는 말하지 않는다.**
- **길이**: 약 5,600 px
- **시간대**: 이른 아침, 옅은 안개, 차가운 회색 톤

| 구간 | 내용 |
|---|---|
| 도입 | 셔터가 내려진 가게 앞에서 시작한다. **안내판 3개**(이동 / 점프 / 도움닫기)가 월드에 박혀 있다. |
| 전개 | 좁은 골목, 담장 점프, 하수구 증기 리프트, 떨어지는 화분(타이밍) |
| 절정 | 횡단보도 — 주기적으로 지나가는 자동차 사이를 타이밍 맞춰 통과 |
| 세이브 | **모래 놀이터** (전개 시작 지점) → 땅파기 모션 |
| 마무리 | 도시 외곽 고가도로. 멀리 바다가 보인다. |

- **안내판**: 월드에 고정된 이미지 오브젝트. 지나가면 카메라와 함께 뒤로 밀려나고,
  되돌아오면 다시 볼 수 있다. 키캡 그림 + 화살표 + 강아지 실루엣만으로 구성 (문자 없음).

### 8.2 스테이지 2 — 해안가

- **컨셉**: 주인이 차를 타고 도시까지 오가던 길. 여러 번 오갔고, 마지막에 한 번 더 오갔던 길.
- **길이**: 약 6,200 px
- **시간대**: 한낮 → 후반부 노을

| 구간 | 내용 |
|---|---|
| 도입 | 방파제, 테트라포드 점프. 갈매기가 놀라 날아오른다. |
| 전개 | 좁은 해안 도로 — 갓길이 좁고 자동차가 양방향으로 지나간다. |
| 절정 | 밀물 구간 — 파도가 주기적으로 밀려온다. 파도에 닿으면 밀려나므로 물러난 타이밍에 달린다. |
| 세이브 | **파라솔 꽂힌 포장마차 노점** → 그늘 낮잠 모션 |
| 마무리 | 해안 절벽 위. 멀리 산이 보인다. |

- 배경 소품: 등대, 방파제, 부표, 낚싯배, 자판기, 녹슨 가드레일
- **연출**: 지나가는 자동차 중 한 대는 주인의 차와 같은 색이다. 강아지가 잠깐 멈춰 바라본다. (스크립트 이벤트)

### 8.3 스테이지 3 — 산 (최고 난이도)

- **컨셉**: 주인이 살던 집은 산 너머에 있다.
- **길이**: 약 7,000 px
- **시간대**: 밤 → 후반부 여명

| 구간 | 내용 |
|---|---|
| 도입 | 험로 — 가파른 경사, 무너지는 흙 발판, 흔들리는 통나무 다리 |
| 전개 | 냇가 — 물살에 밀리는 디딤돌, 물에 빠지면 하류로 밀려난다 |
| 절정 | 야생동물 + 함정 — 멧돼지 돌진(직선 돌진 후 경직), 낙석(주기적), 부엉이(위협 시선) |
| 세이브 | **놀기 좋은 계곡 연못** → 물장구 모션 |
| 마무리 | 능선. 산 너머로 여명이 트고, 아래에 들판이 보인다. |

- 난이도 장치는 **암기가 아니라 관찰로 풀리게** 배치한다. 모든 위험은 예고 동작(텔레그래프)을 가진다.
  - 멧돼지: 앞발로 땅을 긁는 0.7초 → 돌진
  - 낙석: 위쪽에 그림자 표시 0.5초 → 낙하
  - 무너지는 발판: 밟으면 흔들림 0.4초 → 붕괴

### 8.4 스테이지 4 — 들판 (해방)

- **컨셉**: 주인과 함께 살던 곳. 프롤로그의 그 들판. **사실상 걷기만 하면 된다.**
- **길이**: 약 4,000 px
- **시간대**: 맑은 아침

| 구간 | 내용 |
|---|---|
| 도입 | 완만한 언덕. 나비가 따라온다. 위험 없음. |
| 전개 | 프롤로그 컷 1~3의 실루엣이 반투명하게 겹쳐 나타났다 사라진다. (회상) |
| 절정 | 언덕을 넘으면 **프롤로그와 동일한 집**이 보인다. 냄새 입자가 짙어진다. |
| 세이브 | **놀이용 공** → 코로 툭툭 건드리는 모션 |

- 사망 요소 없음. BGM이 프롤로그 테마의 온전한 버전으로 복귀한다.

## 9. 엔딩 (무성)

```
집 안. 침대에서 자고 있는 어른이 된 주인
  → 문 밖에서 소리 (긁는 소리 / 짧은 울음)
  → 일어나 문으로 걸어가 문을 연다
  → 강아지 도착. 껴안는다
  → 암전
  → 침대에서 눈을 뜬다 (꿈이었다)
  → 문 쪽을 바라본다 …
  → 페이드 아웃 / 크레딧(픽토그램)
```

- 마지막 컷에서 문 앞 바닥에만 아주 옅은 냄새 입자가 하나 남는다. (해석의 여지)

## 10. 화면 · 카메라

- 카메라: `startFollow` + `lerp(0.1, 0.1)`, deadzone 240×120, 스테이지 경계 `setBounds`
- 배경: 3~4겹 패럴랙스 (`scrollFactor` 0.1 / 0.3 / 0.6 / 1.0)
- 세로 기기: 가로 회전 유도 오버레이 (회전 픽토그램, 문자 없음)
- 성능: 모바일 기준 60fps 목표. 파티클 상한, 오브젝트 풀링 사용.

## 11. 에셋이 없어도 돌아가는 구조

AI 에셋 제작 전에도 게임이 플레이 가능해야 하므로:

- `AssetLoader`가 `public/assets/` 에서 실제 파일을 찾고, **없으면 코드로 생성한 플레이스홀더**(도형·그라디언트)를 등록한다.
- 실제 PNG를 규정된 경로/이름으로 넣으면 **코드 수정 없이 자동으로 교체**된다.
- 타이틀의 "스프라이트 추가해서 시작"은 사용자가 로컬 파일을 골라 런타임에 주입하는 경로다.
  (`FileReader` → `texture.addBase64` → 8프레임으로 자동 분할)

에셋 규격과 프롬프트는 다음 문서 참조:
- `.docs/assets-sprites.md` — 8프레임 애니메이션 스프라이트
- `.docs/assets-images.md` — 배경 / 소품 / GUI
- `.docs/assets-audio.md` — BGM / 앰비언스 / SFX
